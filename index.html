01

工具概述

CSV Check 是一个 Python 命令行工具。它读取本地 CSV 文件，检查表头和各行的字段结构，再判断指定的必需列是否齐全。运行后，检查结果直接显示在命令窗口中，原文件不会被修改。

它会检查

  • 文件能否以 UTF-8 编码读取
  • 是否有表头，列名是否为空或重复
  • 每行字段数是否与表头一致
  • 是否包含要求的列名

结果的边界

默认必需列为 id、name、score。

工具不判断分数是否为数字、是否在 0–100 之间，也不验证姓名内容或学号的唯一性。

读懂 PASS

文件通过基础结构检查，并且要求的列名齐全。它不等于“所有数据都正确”。

工作对象：UTF-8 CSV 表格

输入是本地、逗号分隔的 CSV 文件。第一行是表头，后续非空行是数据。UTF-8 BOM 可以接受；空行会跳过。Excel 工作簿 .xlsx 和制表符分隔的 .tsv 不能直接当作受支持的 CSV 使用。

samples/students.csv 课程自带示例
id,name,score
1,Ada,95
2,Lin,88
3,Sam,91
  • 列名区分大小写与空格：Name 或 name 都不等于 name。
  • 结构必须一致：列名不可空白、不可重复；数据行字段数应与表头一致。
  • 允许额外列：默认要求的三列齐全即可，不要求固定顺序。
  • 数据行数不含表头：只有有效表头、没有数据行的文件也可能通过。

使用记事本另存为测试文件时，选择 UTF-8 编码和“所有文件”类型，避免文件名变成 students.csv.txt。

基础 CSV 检查只需要 Python 和完整的课程文件，无需安装第三方 Python 软件包。

需要什么用途与确认方式

04

命令行参数详解

本页的主要入口是 check.py。通用命令格式如下，方括号表示可选部分，实际输入时不要带方括号：

py .\check.py file [--require COLUMN [COLUMN ...]]
参数是否必需作用与默认行为
file必需待检查 CSV 的路径，是位置参数，例如 .\samples\students.csv。省略时显示参数错误。
--require COLUMN …可选指定一个或多个必需列名，默认是 id name score。提供后会替换默认列表；列名区分大小写与空格。
-h / --help可选显示使用说明后退出，不执行 CSV 检查。正常显示帮助时退出码为 0。

默认要求：id、name、score

py .\check.py .\samples\students.csv

替换必需列

下面使用随包的 missing-name.csv，只要求其中已有的 id 和 score 两列，因此应得到 PASS：

py .\check.py .\samples\missing-name.csv --require id score

--require 只改变检查条件，不会更改文件内容。它后面至少要有一个列名；不能单独写 --require。

查看帮助

py .\check.py --help
分清 Python 版本与工具版本

py --version 显示 Python 版本。check.py 的报告首行会显示 CSV Check 版本；check.py 1.0.0 本身没有 --version 参数。

可用选项以该版本的 --help 和源码为准；不要把另一入口 py -m csvcheck 的选项直接套用到 check.py。两者的区别见第 9 章。

检查你自己的文件

将最后一个参数换成 CSV 文件路径；路径中含空格时请加英文双引号。

py .\check.py "C:\数据文件夹\我的成绩表.csv"

上面两个是命令格式示例，请换成实际存在的文件。--require 后至少需要一个列名；它替换默认要求，不会自动改写 CSV 表头。

如何理解报告字段

字段含义
CSV Check当前工具的版本号。
File本次检查的输入文件路径。
Data rows已读取的数据行数，不含表头与空行。
Columns文件中实际读到的列名。
Missing columns缺少的必需列；none 表示没有缺失。
ResultPASS 为检查通过，FAIL 为缺少要求的列。文件无法读取或结构不合法时走 ERROR 分支。

三种结果对应的退出码与获取方式见第 7 章：退出码说明。

07

退出码说明

退出码是程序结束时交给终端的数字，用来区分通过、未通过和运行错误。它不等于报告中的数据行数，也不会默认作为报告的一行显示。

退出码典型场景应如何处理
0有效 CSV 且必需列齐全，Result: PASS；或正常显示 --help。检查命令正常结束。PASS 仍不保证分数内容正确。
1CSV 能读取、结构有效，但缺少必需列，Result: FAIL。检查 Missing columns，修正表头或调整 --require。
2捕获的文件读取或结构错误，显示 ERROR；或参数解析错误，显示 usage。根据具体错误检查路径、编码、表格结构或命令参数。

在 PowerShell 中查看

先运行检查，再立刻查看退出码。以下是两条命令，按顺序逐条执行：

py .\check.py .\samples\missing-name.csv
$LASTEXITCODE

这个例子应显示 1。更换为 students.csv 应显示 0；更换为 empty.csv 应显示 2。

$LASTEXITCODE 记录最近一次本机程序执行的退出码，请在运行其他程序前读取。启动失败、模块导入失败等错误也可能产生其他或相同的数字；仅凭退出码不能判断根因，应结合完整报错。

08

故障排查

先对照完整错误信息。多数问题来自运行位置、文件是否齐全或输入格式，不需要反复重装软件。

找不到 py 命令，或 python --version 没有版本号

当前终端没有找到可用的 Python。先关闭旧终端，再打开新的 PowerShell，执行 py --version。如果仍不可用，检查 Python 是否安装完成，以及 Windows 的 Python 应用执行别名与 PATH 配置。使用官方安装管理器完成环境配置后再验证。

No module named 'csvcheck'

正在运行的 check.py 找不到配套模块。请完整解压课程压缩包，在 01_写作练习 中确认 check.py 与 csvcheck 文件夹同层；不要运行单独复制到桌面的 check.py，也不要直接在压缩包内运行。

这里需要的是随课程附带的本地模块，不应凭名字安装来源不明的同名软件包。

can't open file … check.py / 找不到路径

当前目录不正确，或路径拼写不对。回到资源管理器中的 01_写作练习，在地址栏输入 powershell 打开窗口；确认能看到 check.py 后再运行。含空格的文件路径需放在英文双引号中。

Get-Process：找不到接受实际参数…的位置形式参数

常见原因是把提示符 PS C:\Users\…> 也粘贴进了窗口。它是窗口自动显示的内容，不是命令。在新提示符后只输入代码框中的命令即可；上方历史错误无需删除。

the following arguments are required: file

只输入了 py check.py，漏掉待检查文件。请补齐路径：

py .\check.py .\samples\students.csv
Missing columns: name / Result: FAIL

文件读取成功，但没有符合要求的列名。核对表头中的大小写与前后空格；默认需要 id、name、score。如果有意使用中文或其他列名，通过 --require 指定。课程的 missing-name.csv 本来就会得到 FAIL。

ERROR: File has no header.

文件为空，或第一条记录没有可读取的表头。用文本编辑器确认第一行存在有效列名，例如 id,name,score，再另存为 UTF-8 CSV。

Header names must not be blank / must be unique

表头存在空白列名或重复列名。例如 id,,score 有空列名；id,name,name 有重复列名。为每一列填写非空且唯一的名称后重试。

Row … has … fields; expected …

某条记录的字段数与表头不一致。检查报错位置附近的多余逗号、遗漏字段或引号。含逗号的文本应放在英文双引号中；字段中的英文双引号需要成对转义。报错中的行号来自 CSV 解析器；含跨行字段时不一定等于学生记录序号。

Cannot read a UTF-8 CSV file / 文件格式不对

查看错误末尾的具体原因：文件可能不存在、没有读取权限、编码不是 UTF-8，或 CSV 引号语法错误。先确认路径，再将源文件导出或另存为逗号分隔的 UTF-8 CSV。将 .xlsx 或 .tsv 直接改名为 .csv 不会转换其格式。

仍然无法运行？

保存你输入的命令、完整报错、当前目录，以及 check.py / csvcheck / samples 的文件夹截图。这些信息能帮助老师或同学快速定位问题。

09

源码结构

课程包包含写作练习和后续文档网站两个部分。本页使用的是 01_写作练习 中的 CSV Check 1.0.0；下列为该工具的关键文件。

01_写作练习/
├── check.py                 # 主要命令行入口
├── csvcheck/
│   ├── __init__.py          # 检查逻辑、异常、版本及 JSON 格式化
│   └── __main__.py          # python -m csvcheck 的另一入口
├── samples/
│   ├── students.csv         # 列名齐全：PASS
│   ├── missing-name.csv     # 默认缺少 name：FAIL
│   ├── empty.csv            # 无表头：ERROR
│   └── students.tsv         # 制表符样例，不是逗号分隔 CSV
├── README.md               # 项目说明
└── 我的Quickstart.md        # 写作练习文档
文件 / 函数职责
check.py → main()解析 file 与 --require，调用 inspect_csv，输出文本报告，并返回 0、1 或 2。
inspect_csv()使用 utf-8-sig 与 csv.reader 读取文件，校验结构，统计行数，并返回 columns、row_count、missing_columns、valid。
CsvCheckError将读取问题与结构问题交给入口程序，生成用户可读的错误提示。
format_report()把报告字典格式化为可读的 JSON 文本，供模块入口使用。
__version__声明工具版本，此包为 1.0.0。

从输入到报告

终端命令→check.py 解析参数→inspect_csv 检查文件→报告 / 退出码

另一个入口：py -m csvcheck

它使用相同的检查函数，但输出 JSON，且默认不要求任何特定列。若想与 check.py 的默认必需列保持一致，需要显式指定：

py -m csvcheck .\samples\students.csv --require id name score

模块入口另外支持查询工具版本：

py -m csvcheck --version
